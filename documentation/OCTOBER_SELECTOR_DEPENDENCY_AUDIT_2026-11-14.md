The file bytes consumed by the builder are the generated bytes. This is an opt-in **algorithm replay from archived parsed source rows**, not a raw-PDF selector claim. The [authentic combined final-panel run](AUTHENTIC_SELECTOR_JSON_FINAL_RUN_2026-11-14.md) completed with this connection and reproduced the accepted final decoded hashes and models.

This runs the original selector replay before the October historical builder and checks the generated handoff. It does **not** satisfy a strict six-season raw-source mode and does not change the accepted final SHA-256 targets.
